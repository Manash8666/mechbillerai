# 🚀 Quick Start Guide - Garage SaaS

Get your garage management system up and running in 5 minutes!

## Step 1: Install Dependencies (2 minutes)

```bash
npm install
```

## Step 2: Setup Database (1 minute)

```bash
# Create .env file
cp .env.example .env

# Initialize database
npx prisma generate
npx prisma db push
```

## Step 3: Start the Server (30 seconds)

```bash
npm run dev
```

Visit: **http://localhost:3000**

## Step 4: Create Your Account (1 minute)

1. Click "Get Started" or go to `/register`
2. Fill in your details
3. **Save your license key!** (You'll need it)
4. Login with your credentials

## Step 5: Start Using! (30 seconds)

You're now on the dashboard! Start with:

1. **Add a Customer**: Click "Customers" → "Add Customer"
2. **Add a Vehicle**: In customer details, add their vehicle
3. **Create Job Card**: Go to "Job Cards" → "New Job Card"
4. **Generate Invoice**: After job completion, create invoice

## 🎉 That's It!

You now have a fully functional garage management system.

## 📱 Quick Tips

### For Daily Use:

- **Dashboard**: See all important metrics

### For Setup:

- **Inventory**: Add your parts/spares
